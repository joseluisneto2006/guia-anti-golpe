# Guia Anti-Golpe Digital

Projeto acadêmico desenvolvido com HTML, CSS e JavaScript básicos.

## Organização

- `pages/`: páginas do site.
- `css/geral.css`: estilos compartilhados.
- `css/`: estilos específicos de cada página.
- `js/`: scripts das páginas com funcionalidades interativas.
- `img/`: imagens do projeto.

## Como abrir o projeto

Abra `pages/index.html` para acessar o cadastro e, em seguida, faça login para
ir ao conteúdo principal do guia em `pages/inicio.html`.

## Login e cadastro

O login e o cadastro são demonstrações acadêmicas que utilizam `localStorage`
para guardar os dados no navegador atual. Eles não implementam autenticação
real e não utilizam banco de dados. Os dados ficam disponíveis somente no
navegador em que o cadastro foi feito.
